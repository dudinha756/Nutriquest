# NutriQuest

Aplicativo web de acompanhamento de dieta com gamificação.

## Recursos
- refeições diárias e conclusão por etapa
- meta de água
- XP e níveis
- NutriCoins
- sequência de dias
- progresso semanal
- recompensas personalizadas
- persistência local no MVP
- schema PostgreSQL pronto para Neon

## Stack
Next.js + React + TypeScript, GitHub, Vercel e Neon PostgreSQL.

## Rodar
```bash
npm install
npm run dev
```

## Deploy
Importe este repositório na Vercel. Depois, conecte o Neon e adicione `DATABASE_URL` nas variáveis de ambiente.
